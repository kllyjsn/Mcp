# MCP — Music Composition Platform

An AI-powered composition engine and DAW-style production environment built for musicians who care about harmonic depth, dynamic expression, and sonic detail.

## Features

- **AI Composition Engine** — generates multi-track arrangements using music theory: voice-led chord progressions, contour-shaped melodies, rhythmic pattern generation, and dynamic curves
- **Classical Harmony** — diatonic chord analysis, circle-of-fifths progressions, jazz ii-V-I patterns, neo-soul voicings, and 14+ progression templates across 9 styles
- **12 Scales & Modes** — Major, Minor (Natural/Harmonic/Melodic), Dorian, Phrygian, Lydian, Mixolydian, Pentatonic, Blues, Whole Tone, Diminished
- **5-Track Arrangement** — Melody, Harmony (strings), Bass, Arpeggio (bells), Drums — each with independent effects chains
- **DAW-Style Views** — Arrangement (timeline), Mixer (channel strips with faders/pan/mute/solo), Piano Roll (note-level editing view)
- **Real-Time Playback** — Tone.js synthesis with reverb, delay, chorus, compression, EQ, and a mastered output chain
- **Expression Controls** — Harmonic complexity, melodic density, rhythmic variety, expressiveness sliders that shape the AI's output
- **Per-Track Regeneration** — regenerate any single track while keeping the rest of the arrangement intact

## Quick Start

```bash
npm install
npm run dev
```
